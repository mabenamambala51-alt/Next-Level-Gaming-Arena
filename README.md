# Next Level Gaming Arena

The Mobile Application for a gaming company which allows you to see their services and book. This repository contains a responsive multi-page gaming and indoor-sports arena app.

## Run locally

Open `index.html` in a browser, or use the included VS Code launch configuration.

## Pages

- Home (`index.html`)
- Games, Sports, Tournaments, Events, Booking, Leaderboard, Membership, Parties, Community, About, and Booking Status (`pages/`)

Shared styles and interactions are in `assets/arena.css` and `assets/arena.js`.

Booking requests, membership selections, event sign-ups, and community posts in this frontend demo are stored in the browser's local storage. No server, payment processing, or live booking service is connected.
